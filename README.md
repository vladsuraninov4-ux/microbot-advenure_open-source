# 🤖 Microbot Adventure

**Космический раннер с процедурной генерацией. Ноль ассетов — всё нарисовано кодом.**

![Gameplay Screenshot](https://via.placeholder.com/800x400?text=Microbot+Adventure+Screenshot)

## 🌌 О чём игра
Ты — добрый робот, который бежит по бесконечному небесному мосту над огненным морем в открытом космосе. Твоя задача — перепрыгивать платформы, давить грибов-киборгов и не упасть в лаву. 

Уровень генерируется процедурно: каждый забег уникален.

## ✨ Особенности
- 🎨 **Zero-Asset:** Ни одной картинки из интернета. Робот, враги, звёзды и лава рисуются математикой в реальном времени.
- 🍄 **Грибы-киборги:** Умные враги с AI патрулирования и анимацией сплющивания.
- 📱 **Мобильное управление:** Работает и на ПК, и на телефонах (кнопки создаются кодом).
- ⚡ **Безумная оптимизация:** 120+ FPS на любом железе. Весит меньше, чем скриншот из AAA-игры.
- 🌠 **Параллакс-космос:** Два слоя звёзд и планеты на фоне.

## 🛠️ Технологии
- **Движок:** Godot 4.2 (GDScript)
- **ОС:** Arch Linux 🐧
- **Время разработки:** 3 дня (от скуки)
